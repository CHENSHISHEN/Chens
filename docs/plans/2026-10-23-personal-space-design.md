# chen / space 首版设计

用户确认模块：博客、项目、知识库、工具箱、关于。

保留 Astro Devosfera 的 Astro 静态构建、Markdown 内容、本地字体、网格背景、光晕与 Pagefind 搜索。品牌暂用 chen / space。

桌面使用顶部模块导航、左侧分类、中间内容的布局。手机隐藏侧栏，以顶部菜单与博客筛选访问所有主题。主色为暗灰、琥珀色，配合紫、绿、蓝色主题标记，支持明暗主题和减少动态效果设置。

首页：个人简介、四模块入口、精选文章、最近更新与探索卡片。博客提供四主题筛选与正文页；项目提供列表与详情；知识库按主题链接文章；工具箱提供 JSON 格式化、时间戳转换与文本统计；关于页留待用户补充真实经历。

示例文章、概念项目和待确认个人文案均明确标注。原模板文章保留为草稿。模块资料集中于 src/data/space.ts，文章存放在 src/data/blog/chen。未部署，未创建远程仓库。

验证：Astro 类型检查与静态构建；桌面/手机排版；导航、分类筛选、详情、搜索、工具与主题切换。
